# Rossmann Store Sales Forecasting - End-to-End Linear Regression Project

## Project Overview
Predict daily sales across Rossmann drug stores using exploratory data analysis (EDA), rigorous feature engineering, and Linear Regression (along with regularized variants: Ridge, Lasso, ElasticNet).

## Directory Structure
- `data/raw/`: Store raw downloaded files (`train.csv`, `store.csv`, `test.csv`).
- `data/processed/`: Cleaned and merged feature sets.
- `notebooks/`: Exploratory analysis and prototype experiments.
- `src/`: Modular, reusable production code (data loading, transformations, modeling).
- `saved_models/`: Serialized model artifacts, encoders, and scalers.
- `reports/figures/`: Exported charts and summary metrics.
